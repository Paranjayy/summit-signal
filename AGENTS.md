# Project Agent Contract

## Mission

Ship a fast, expressive browser climbing game that feels physical and replayable.

## Current stage

Public prototype. Optimize for readable play, visual character, performance, and low operational complexity.

## Commands

- Install: `npm install`
- Develop: `npm run dev`
- Lint: `npm run lint`
- Build: `npm run build`

## Guardrails

- Keep gameplay client-side unless persistent services earn their cost.
- Do not use proprietary game assets or branding.
- Verify lint and build before commits and deployment.
