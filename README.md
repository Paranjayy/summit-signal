# Summit Signal

An original browser 3D climbing game. Navigate a vertical route of industrial debris, cloud platforms, and signal towers—each landing triggers the next leap. Built with React, Three.js, React Three Fiber, and procedural geometry.

## Commands

- `npm run dev` — local development
- `npm run lint` — lint source
- `npm run build` — type-check and production build

## Controls

Move with WASD or the arrow keys. `R` resets a run. The character auto-bounces on every safe landing.

## Asset policy

The world’s meshes and material treatments are original procedural work. No proprietary game assets, names, branding, levels, or art are reused.
